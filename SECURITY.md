# Security policy

Please report vulnerabilities using the fork's [private security advisory form](https://github.com/doggylover314/ytm-offline/security/advisories/new). If private reporting is unavailable, open an issue without publishing credentials, cookies, or exploit details.

Include the affected version, Linux distribution, steps to reproduce, and the impact. Session credentials, local files, privileged webview access, and update/package integrity are in scope.
